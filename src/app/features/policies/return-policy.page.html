Return Policy

Effective Date: February 26, 2026

1. Return Window

Returns are accepted strictly within 3 calendar days from the date of successful delivery. Return requests beyond 3 days are not accepted.

2. Mandatory Pre-Return Communication

Before sending any return, customer must first contact Zaava Collection support on WhatsApp/Call: +91 84858 96373. Returns sent directly without prior communication and approval are not accepted.

  • Customer must share order ID, issue details and product images/video (if asked).
  • Return is valid only after explicit approval from store owner/team.

3. Eligible Condition for Return

  • Product must be unused, unwashed and in original condition.
  • Original tags, packaging and invoice/proof must be available.
  • Any signs of wear, alteration or damage after delivery are not eligible for return.

4. Approved Return Dispatch Timeline and Process

After return approval from owner/team, customer must send/submit the product within 3 days of approval. If not returned within this approved timeline, return request will be treated as cancelled and not acceptable.

  • By courier to store return address, or
  • By physically visiting the store with product and invoice within approval window.

Store Return Address: Zaava Collection, MG Road, Pune, Maharashtra, India

5. Charges and Refund Rules

  • Return courier charges are to be borne by customer unless approved otherwise by store.
  • Original delivery charges are non-refundable.
  • After product quality verification, refund/credit is processed as per approved mode.

6. Post-Delivery Liability

After successful delivery confirmation, Zaava Collection and business owner are not liable for customer-side damage, mishandling, misuse or delayed return requests beyond policy window.

To initiate return support within policy window, contact +91 84858 96373.
